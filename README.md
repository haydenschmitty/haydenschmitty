## 🔨 Building now

<a href="https://github.com/haydenschmitty/floorplan"><img src="https://raw.githubusercontent.com/haydenschmitty/floorplan/main/docs/images/video.jpg" alt="Floorplan: an interactive, plain-English map of your codebase" width="100%"></a>

**[Floorplan](https://github.com/haydenschmitty/floorplan)**: see how your app actually fits together. A plugin for Claude Code and Codex that maps your whole codebase into an interactive, plain-English floorplan, with a health check that flags exposed API keys and endpoints anyone can change. Free and open source.
